Personal portfolio for Kyoseok Hwang, an M.S. Data Science candidate focused on data analytics and technical operations.

Live site: <https://bob-kyo.github.io>

## Public sections

- About
- Projects
- Resume

## Local build

This site uses Jekyll and the AcademicPages/Minimal Mistakes theme structure.

```bash
bundle install
bundle exec jekyll build
```

## Content policy

Only verified public projects and career information are included. Private repositories, credentials, and internal project details are intentionally excluded.
